## Principios de diseño

Cuando diseñes interfaces web:
- Usa variables CSS para colores y tipografía
- Diseña mobile-first con flexbox/grid
- Aplica jerarquía visual y espacio en blanco generoso
- Prefiere componentes reutilizables y modulares
- Sigue accesibilidad WCAG AA: contraste, aria-labels, HTML semántico

## Stack preferido

- HTML5 semántico
- CSS moderno (custom properties, grid, flexbox)
- React con hooks funcionales
- Tailwind para utilidades

## Entrega

Siempre entrega código completo, sin placeholders, listo para usar.
